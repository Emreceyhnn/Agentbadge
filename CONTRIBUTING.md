# Contributing to agentbadge

We welcome contributions to make repositories more accessible and productive for autonomous coding agents!

## Development Setup

```bash
pnpm install
pnpm run build
pnpm run test
pnpm run lint
```

## Pull Request Guidelines

1. Ensure all tests pass.
2. Keep strict type safety (no `any` types).
3. Update tests when modifying scoring rules or remediation diffs.
